# Final Materials Checklist

本目录用于存放课程要求中的最终文档材料。提交前应将下面的占位项替换为最终文件。

## 必需材料

- [ ] Final report（PDF 或 HTML）
- [ ] Literature review and research questions
- [ ] Dashboard design specification / thought framework
- [ ] Presentation slides（PPTX 或 PDF）
- [ ] Individual reflection（最终版，不得保留 `[insert ...]` 占位符）

代码、数据处理、EDA 和 Shiny 应用分别位于上一级目录的正式子包中。本目录只负责最终叙事材料，不复制源代码和大型数据文件。
